# Таблица входов и выходов

## Входные данные

| Имя в модели | Тип в C | Обоснование типа |
|---|---|---|
| `distance_km` | `double` | Длина маршрута — величина (120.5 км, 81.5 км), дробная часть значима, `int` её обрежет |
| `duration_minutes` | `int` | Минуты поездки моделируются как целое число |
| `battery_capacity_kwh` | `double` | Ёмкость батареи — величина с дробной частью (64.0, 46.0), участвует в делении |
| `start_charge_percent` | `double` | Процент заряда — дробный (например, 87.3%, 82.0%), участвует в вычитании и делении на 100.0 |
| `finish_charge_percent` | `double` | Аналогично: дробный процент (42.6%, 54.5%) |
| `tariff_byn_per_kwh` | `double` | Тариф задаётся с несколькими знаками после запятой (0.295, 0.42) — дробная величина |
| `passengers` | `int` | Число пассажиров по смыслу может быть только целым |

## Выходные данные

| Результат | Тип в C | Обоснование типа |
|---|---|---|
| `time_hours` | `double` | Результат деления `duration_minutes / 60.0`; даже если минуты целые, часы почти всегда получаются дробными (95 мин → 1.5833... ч) |
| `energy_used_kwh` | `double` | Результат умножения/деления дробных величин (ёмкость × разница процентов / 100.0); дробное по построению |
| `average_speed_kmh` | `double` | Частное `distance_km / time_hours`, результат дробный |
| `consumption_kwh_per_100km` | `double` | Частное с умножением на 100.0; итог не выражается целым числом в общем случае |
| `trip_cost_byn` | `double` | Произведение энергии на тариф — денежная величина, требует точности до копеек |
| `cost_per_passenger_byn` | `double` | Частное `trip_cost_byn / passengers`; даже если `passengers` — `int`, при делении на него результат остаётся дробным денежным значением |
